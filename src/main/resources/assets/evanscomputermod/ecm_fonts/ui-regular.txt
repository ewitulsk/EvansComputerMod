# ECM "ui" font, regular design (12 lu line). Original pixel design for
# EvansComputerMod; the single source of truth for every renderer.
# Format (scripts/gen-ui-fonts.py):
#   glyph <c> @<row>    rows follow until a blank line; width = row length
#   glyph <c> w<n>      an empty glyph n wide (spaces)
#   mark <name>         a diacritic bitmap, rows until a blank line
#   compose <c> <base> <mark> @<row>   base glyph + mark centred at that row
#   alias <c> <c2>      same glyph as c2
# <c> is the character itself or U+XXXX. '#' = ink, '.' = paper.
# Advance = width + spacing. Rows: 0-1 accents on capitals, 2-8 capitals and
# ascenders, 4-8 x-height, baseline under row 8, 9-10 descenders, 11 gap.
