NAME
    terminal-app - the Terminal app: a shell in a GUI window

SYNOPSIS
    terminal

DESCRIPTION
    The Terminal app (dev.ecm.terminal, program terminal) opens a window
    with a shell session of its own: the same shell as the console, so
    every command works in it. Start it from the desktop's launcher,
    from the ePhone's home screen, or by typing terminal in another one.
    Needs the GUI. Programs typed in it run unconfined, as at the
    console.

    The window's size sets the terminal's size in characters (8x16
    cells): make the window bigger for more columns and rows. Below 320
    lu wide (an ePhone) the grid has no border, so a phone gets 30
    columns.

    Colours, bold, underline and inverse text are shown as programs
    write them; the cursor is a block. When the shell ends the window
    says "[session ended - close the window]". Closing the window ends
    the session. A computer has at most 8 shell sessions; with none free
    the window says so.

KEYS
    The shell's line editing (Left/Right, word jumps, history, Ctrl+R,
    Tab completion) works here as everywhere: see man keys.

    Ctrl+Shift+C, Ctrl+Insert
        Copy the selected text to the clipboard.

    Ctrl+Shift+V, Shift+Insert
        Paste the clipboard as typed text (a Tab in it doesn't
        complete); every newline becomes Enter.

    Shift+PageUp, Shift+PageDown, Shift+Up, Shift+Down
        Scroll back through the last 1000 lines, a page or a line at a
        time; Shift+Home and Shift+End go to the oldest line and back to
        the bottom. The mouse wheel scrolls 3 lines. While scrolled back
        the top-right corner shows how far; the view stays put while
        output arrives, and typing goes back to the bottom. A
        full-screen program (edit, man, less) gets the wheel as Up and
        Down instead.

    Ctrl+letter
        Sent to the program as a control character. Ctrl+C or Ctrl+T
        stops the running program (a full-screen program gets Ctrl+C as
        a key).

    Enter, Backspace, Tab, Esc, arrows, Home, End, PageUp, PageDown,
    Insert, Delete, F1-F12
        Sent as the usual xterm keys, with Shift, Alt and Ctrl as the
        modifier parameter (Ctrl+Left is ESC[1;5D, a word left). At the
        Terminal block, Esc closes the screen: Shift+Esc sends Esc.

MOUSE
    Drag with the left button to select text; double click selects a
    word, triple click a line; a click without a drag clears the
    selection. The right button opens a menu: Copy, Paste,
    Clear selection.

NOTES
    Ctrl+C without Shift goes to the program and stops it: copy with
    Ctrl+Shift+C or the right-click menu.
