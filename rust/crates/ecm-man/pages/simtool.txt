NAME
    simtool - write and inspect SIM cards in a Card Reader/Writer

SYNOPSIS
    simtool [--reader NAME] [info]

    simtool [--reader NAME] write <imsi> <carrier> [--key HEX|--random]

    simtool [--reader NAME] auth <challenge-hex>

    simtool [--reader NAME] eject

    simtool [--reader NAME] wait [seconds]

DESCRIPTION
    Works with the card in a Card Reader/Writer placed against any side
    of the computer. A SIM card is blank until written; a written card
    holds its carrier, its IMSI (its number) and a secret 16-byte key
    that can never be read back: it only answers challenges. To run a
    network, cored sim new is easier (it writes the card and adds it to
    the database in one step); simtool is for doing it by hand.

COMMANDS
    info
        The default. No card, a blank SIM, or the SIM's IMSI and
        carrier; whether the card is held for this computer or
        released, and the reader's Auto Eject Sim setting.

    write <imsi> <carrier>
        Write a blank SIM: IMSI 6-15 digits, carrier 1-24 of a-z, 0-9,
        _ and -. The key is random (--random, the default) or given
        with --key (32 hex digits). It is printed once: put it in the
        carrier's database (cored add <imsi> <key>). Writing releases
        the card.

    auth <challenge-hex>
        The card's answer (res) and session keys (ks) to a 16-byte
        challenge (32 hex digits), for testing.

    eject
        Release the card: Auto Eject Sim pushes it into an adjacent
        inventory, otherwise it waits to be taken or pulled out.

    wait [seconds]
        Wait (default 30 s) for the reader's next card_inserted or
        card_removed event.

OPTIONS
    --reader NAME
        Which Card Reader/Writer, when there are several. Default the
        first.

EXAMPLES
      simtool
      simtool write 001010000000001 cell-red
      simtool auth 000102030405060708090a0b0c0d0e0f
      simtool wait 60

NOTES
    Put a card in by right-clicking the reader with it; take it out
    with an empty hand. A written card can't be written again.
