NAME
    intro - start here: using a computer's terminal

DESCRIPTION
    Right-click a Terminal block to use its screen. You type commands at
    the prompt (/ >) and press Enter; programs print their results below.
    Shift+Esc closes the screen; the computer keeps running. Esc itself
    is a key for the computer, and Ctrl+C stops a running program.

FIRST COMMANDS
      help              every command and topic, by subject
      help ls           what ls does, in short
      man ls            the whole manual page for ls
      man -k network    find pages about a subject
      ls                the files here
      cd home           go into the home directory
      edit hello.py     write a file (Ctrl+S saves)
      python hello.py   run it

GETTING AROUND
    Left and Right move inside the line, Up recalls earlier commands,
    Ctrl+R searches them, and Tab finishes command and file names. The
    mouse wheel and Shift+PageUp scroll back over output. Drag to select
    text and press Ctrl+C to copy it; Ctrl+V pastes. Ctrl+C with nothing
    selected stops the running program. All the keys: man keys.

WHERE NEXT
    man shell (pipes, redirects, jobs), man filesystem (where files
    live), man networking, man radio, man gui (the desktop),
    man scripting (Python and Lua), man phone-guide (the ePhone).
