NAME
    gui - start, switch and stop the graphical desktop

SYNOPSIS
    gui
    gui start | console | show | toggle | stop | status
    gui launch PROG [ARGS...]

DESCRIPTION
    A Terminal starts in console mode: a text screen with the shell.
    gui starts the graphical user interface (the GUI): a compositor that
    draws windows on the Terminal's display and a shell program that
    draws the desktop around them (by default the desktop, see desktop).
    The console keeps running behind the GUI.

    gui writes one command to the computer's GUI device, /dev/uictl, and
    prints the answer.

COMMANDS
    start
        Start the GUI and show it. The same as gui with no arguments.

    console
        Show the console again. The GUI and its apps keep running.

    show
        Show the GUI again after gui console.

    toggle
        Switch between the console and the GUI.

    stop
        Close the GUI and every window in it.

    status
        Say what runs, one line per window.

    launch PROG [ARGS...]
        Start a program, or an installed app by its id, as a GUI app. It
        runs outside the console's job control, so the prompt comes back
        at once and the app keeps running.

KEYS
    Ctrl+Alt+Backspace
        Switch between the console and the GUI, from either side (like
        gui toggle). Only the side on screen gets the keys. It does
        nothing on an ePhone, which is always in the GUI.

FILES
    /etc/ui.toml
        GUI settings, edited by Settings > Appearance. autostart = true
        starts the GUI when the computer boots. shell names the shell
        program (dev.ecm.desktop by default; test-shell is a simple
        tiling shell) and shell_args its arguments. theme is the colour
        theme: ecm-default, ecm-light, ecm-ocean or ecm-contrast.

    /dev/uictl
        The GUI control device gui talks to.

EXAMPLES
      gui
      gui status
      gui launch notes
      gui launch dev.ecm.store
      gui console
      gui stop

NOTES
    GUI apps (files, editor, settings, store, ...) need the GUI: typed
    in the console without it they say to start the GUI with gui, and
    exit. A program that draws graphics while the GUI is up gets a
    window of its own.

    A new shell chosen in /etc/ui.toml starts with the next gui (gui
    stop, then gui). On a computer without a GUI device gui says "no GUI
    device on this computer".
