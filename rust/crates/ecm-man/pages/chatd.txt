NAME
    chatd - run a chat server (one room)

SYNOPSIS
    chatd [PORT] [--room NAME]

DESCRIPTION
    Listens on TCP (default port 7777) and runs one chat room for chat
    and the Chat app: nicknames, every message sent to everyone with a
    timestamp, join and leave notices, and recent history replayed to
    whoever joins. It logs what happens with the time of day. A client
    that disconnects is dropped without affecting the others.

    chatd announces itself for service discovery under the room's name
    (in /run/disco), so computers find it with disco or chat when this
    computer runs disco serve.

    chatd runs until you stop it with Ctrl+T. Start it with chatd & or
    put chatd & in /services.cfg.

OPTIONS
    PORT
        The TCP port to listen on.

    --room NAME
        The room's name (default Tech Village chat).

EXAMPLES
      chatd &
      chatd 7000 --room Lab &
      disco serve &
