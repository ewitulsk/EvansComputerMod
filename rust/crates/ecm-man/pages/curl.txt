NAME
    curl - fetch a web page or send data to a web server

SYNOPSIS
    curl [-v] [-L] [-k] [-I] [-f] [-s] [-o FILE | -O] [-X METHOD]
         [-d DATA] [-H HEADER] <url>

DESCRIPTION
    Makes one HTTP request and prints the body of the reply. The URL is
    http://host[:port]/path or https://host[:port]/path; the http://
    may be left out, and the port defaults to 80 (443 for https). The
    host can be an address or a name (the search domain applies, so
    curl http://web/ works in a village).

    An https server's certificate is checked (man tls). If the name
    cannot be found, the connection fails or the certificate is
    refused, curl says so and why.

    Real websites need a computer with a way to an Internet Gateway and
    the internet add-on (evanscomputermod-internet) on the server.
    Addresses on the server's own LAN are refused: curl prints Failed
    to connect.

OPTIONS
    -v
        Also print the request line and the reply's headers.

    -L
        Follow redirects (at most five).

    -k
        Accept any certificate. The connection is still encrypted, but
        you no longer know who answers.

    -I
        Ask for the headers only (HEAD) and print them.

    -f
        Fail without printing the page when the server answers with an
        error (404, 500, ...).

    -s
        No progress or error messages.

    -o FILE
        Save the body in FILE instead of printing it. Nothing is left
        behind when the download fails.

    -O
        Save it under the address's file name.

    -X METHOD
        Use this method (GET by default).

    -d DATA
        Send DATA as the request body. Turns GET into POST and sets
        Content-Type: application/x-www-form-urlencoded unless -H gives
        another.

    -H HEADER
        Add a header, written Name: value (quote it).

EXAMPLES
      curl http://100.72.0.10/
      curl http://web.v4.ring/index.html
      curl -v http://10.0.0.5:8080/
      curl -d "op=list" http://nic.ring/api
      curl -H "Content-Type: text/plain" -d hi http://10.0.0.5/a.txt
      curl https://100.72.0.10/
      curl -L -O https://example.com/file.txt
